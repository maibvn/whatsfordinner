# What's for Dinner?

A modern web application that suggests Vietnamese dishes based on your mood and preferences. Built with vanilla JavaScript and powered by OpenAI's GPT model.

## Features

- Clean, modern user interface
- Real-time dish suggestions based on user mood
- Detailed information about suggested dishes including:
  - Dish name
  - Description
  - Type of dish
  - Region of origin
  - Key ingredients
- Responsive design that works on all devices
- Smooth animations and transitions

## Setup

1. Clone this repository
2. Create a `.env` file in the root directory with your OpenAI API key:
   ```
   OPENAI_API_KEY=your_api_key_here
   ```
3. Open `index.html` in your web browser

## Requirements

- Modern web browser with JavaScript enabled
- OpenAI API key (get one at https://platform.openai.com/api-keys)

## Usage

1. Enter your mood or preferences in the text area (e.g., "I'm feeling like something spicy" or "I want something light and healthy")
2. Click "Get Dinner Suggestion"
3. Wait for the AI to analyze your preferences
4. View your personalized Vietnamese dish suggestion

## Technologies Used

- HTML5
- CSS3 (with CSS Variables and Flexbox)
- Vanilla JavaScript (ES6+)
- OpenAI GPT-3.5 API
- Modern CSS animations and transitions

## Note

This application requires an active internet connection to communicate with the OpenAI API. Make sure you have a valid API key and sufficient credits in your OpenAI account.
